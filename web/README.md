# dsl-exp Editor

A visual editor for dsl-exp workflows.

## Features
- Visual graph editing using React Flow
- Property editor for DSL nodes
- Import/Export YAML workflows
- Auto-layout support

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Open http://localhost:5173 in your browser.

## Building

To build for production:
```bash
npm run build
```
